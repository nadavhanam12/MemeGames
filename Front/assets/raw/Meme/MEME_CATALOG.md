# Hormuz Hold'em — Meme Atlas Catalog

All atlases are opaque 2048×2048 PNG files arranged as a 2×2 grid of four 1024×1024 runtime-captioned memes. Every individual quadrant contains Donald Trump and/or Mojtaba Khamenei, and the four quadrants within each atlas use different roles, wardrobes, environments, palettes, and gameplay states.
