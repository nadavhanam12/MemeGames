## Character-selection rule

Future meme atlases are not limited to a fixed recurring cast: select the four characters that best communicate each joke, including public figures and fictional Iranian, American, European, military, civilian, maritime, media, financial, or diplomatic archetypes while keeping every atlas internally consistent.

When a future meme specifically requires Iran's leader, use Mojtaba Khamenei rather than the earlier generic elderly supreme-leader design; existing approved atlases are not changed automatically.

## Reference-composition rule

For every supplied reference meme, treat its composition as locked: preserve the same panel structure, camera angle, crop, character count, left/center/right placement, pose, gaze direction, gesture, foreground/background depth, negative space, and caption zones as closely as possible; change only character identities, clothing, game-specific narrative elements, and runtime text unless the user explicitly requests another compositional change.
